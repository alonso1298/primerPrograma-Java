# Primer Programa en Java 🚀

Este repositorio contiene un ejemplo básico de código en Java, ideal para quienes están comenzando a programar en este lenguaje. Se incluye un programa sencillo que imprime un mensaje por consola.

## 🔧 Requisitos

- Tener instalado Java Development Kit (JDK)

- Un editor de texto o un entorno de desarrollo (como IntelliJ IDEA, Eclipse o VS Code)

## 📚 Ejecución del programa

1. Clona el repositorio:

```bash
git clone https://github.com/alonso1298/primerPrograma-Java.git
cd primerPrograma-Java
```

2. Compila el archivo Java:

```
javac Main.java
```
